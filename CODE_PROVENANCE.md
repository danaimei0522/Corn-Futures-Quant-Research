# Code provenance and project license status

## Scope reviewed

The candidate includes nine Python scripts generated and developed as project-specific research code during this Quant Research collaboration, plus a package verifier. They implement project-specific data assembly, technical indicators, strategy simulation, Rank IC/HAC analysis, and validation checks. Static review found no vendored source from AKShare or numerical libraries, no identifiable third-party implementation blocks, and no broker SDK or order-submission implementation.

OpenAI's current [Terms of Use](https://openai.com/policies/row-terms-of-use/?app=1) state that, as between the user and OpenAI and to the extent permitted by law, the user owns outputs and OpenAI assigns any rights it may have. The terms also caution that outputs may not be unique and place responsibility for use on the user. The project scripts were created in response to the user's research instructions, and no third-party source code was copied into this subset. On that basis, the code-only bundle is prepared for public display as the user's project output. This is a provenance record, not a legal opinion or a guarantee of copyrightability/uniqueness.

The local workspace has no commit history or per-file authorship metadata, so the filesystem alone does not provide a line-by-line author trail.
